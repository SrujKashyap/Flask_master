CodeForge Arena — Backend

A competitive programming platform backend that supports user authentication, problem management, and live code execution — built with Flask and PostgreSQL.
🌐 Live Site: https://forgecode.in

Features:

🔐 User Authentication — Secure registration and login with hashed passwords and session management
📋 Problem Management — CRUD API for coding problems with metadata (difficulty, tags, test cases)
⚙️ Code Execution Engine — Accepts user-submitted code, runs it against test cases, and returns results
🗃️ PostgreSQL Database — Persistent storage for users, problems, submissions, and results
🔌 RESTful API — Clean JSON endpoints consumed by the frontend

🚧 This project is no longer actively maintained. It was built as a learning project to explore backend architecture, REST API design, and dynamic code execution with Python and Flask.
